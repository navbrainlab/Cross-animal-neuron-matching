# 不同活动窗口下的匹配

## 结论

- Atanas：480 秒的 Top-1 仅保留完整记录的 89.13%；900 秒达到
  99.15%。按预设的“完整记录 Top-1 的 95%”标准，最短测试时长为
  **900 秒（15 分钟）**。
- Kato/RLD：480 秒保留 74.76%，900 秒保留 94.19%。因此 900 秒可满足
  90% 标准，但没有任何短窗口达到 95%；按 95% 标准需要 **超过 900 秒，
  当前数据上只能记为完整记录（约 15.2–24 分钟）**。
- 同时段长度的前/中/后窗口给出的逐神经元 Top-1 预测并不完全稳定。480 秒时
  Atanas 的两两一致率为 72.44%，Kato/RLD 为 55.80%；900 秒时分别为
  84.73% 和 72.13%。这说明活动线索存在明显时间非平稳性，Kato/RLD 更强。

## 固定协议与审计

- 固定 seed42 checkpoint 和每个 fold 的训练期 population atlas；不重训、不调参。
- 只裁剪 held-out query 的活动，坐标、候选身份和评估 query 集合均不变。
- 按物理秒数切窗，短窗口独立线性重采样到模型训练时的 512 个时间点。
- 15–900 秒均取记录的前、中、后三个位置；完整记录作为历史结果复现锚点。
- 10 个 dataset/fold 的完整记录 Top-1、Top-5、MRR、Hungarian 和 query 数均与
  历史保存结果逐项精确相同。

需要注意：900 秒窗口在较短记录中高度重叠，所以该时长的一致率对“独立时间段
稳定性”偏乐观。Kato/RLD 的最短记录约 913 秒，无法在保持全部 95 个测试动物
不变的前提下继续测试更长的统一短窗口。

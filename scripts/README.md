# Scripts

- `neurid/run_cv5.py`: canonical Atanas/Kato five-fold runner.
- `check_release.py`: fail-closed public-tree and data-layout validation.
- `lib/`: shared baseline protocol helpers.
- `zebrafish/query_record_io.py`: query-record schema used by baseline adapters.

Historical model-version launchers are intentionally not included.
